# JayaMadhesh | 3D Modeling & Animation Portfolio

A responsive personal portfolio showcasing my 3D modeling projects,
hard-surface assets, character models, animation work, and interactive
3D experiences.

Built with HTML, CSS, JavaScript, and Three.js, this portfolio presents
my creative work, technical skills, education, and ongoing projects.

---
### 🌐 View My Live Portfolio

**[Open My Portfolio Website](https://jayamadheshjm-cpu.github.io/Portfolio-website/projects.html)**


## 🌐 Website Overview

The portfolio contains three main pages:

### 1. Home — `index.html`
- Personal profile and introduction
- Education and academic background
- Profile photograph with a particle hover effect
- Responsive layout for desktop and mobile devices

### 2. Projects & 3D Showcase — `projects.html`
- Project cards featuring selected modeling work
- Interactive 3D model viewer
- Browser-based visualization of hosted 3D models
- Local model preview for supported file formats

### 3. Skills & Contact — `contact.html`
- Technical skills and proficiency levels
- Languages and proficiency descriptions
- Additional skills and interests
- Current learning goals
- Contact information and external links

---

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layouts, and animations
- **JavaScript** — Interactive functionality
- **Three.js** — Real-time 3D visualization
- **Maya** — 3D modeling and asset creation
- **Blender** — 3D modeling and asset preparation
- **Substance Painter** — Material and texture workflows
